A docs assistant over the Hatchet docs

A short demo I built on Hatchet's public documentation (123 pages), running fully locally on a laptop.

  • Every answer cites the exact docs section it came from.
  • When the docs don't cover a question, it says so instead of guessing.
  • Runs on a local open model: no questions or docs are sent to any third-party AI provider.
